# 提交前最后检查

本目录完成的是本地实验与交付材料。没有代你公开发布仓库、填写学号或提交课程网站。

1. 阅读 `学习说明_步骤与文件.md`，重点理解门控前馈、因果预测、BPB、验证集选择和消融。
2. 阅读 `output/pdf/MP1_Report.pdf`，核对是否准确表达你理解的方法与结果。不要删除 README 中的 AI 披露与复用声明。
3. 把 `deliverables/MP1_source.zip` 的内容解压并上传自己的代码仓库，保留数据归属说明、报告、复现说明和结果日志。
4. 提供固定 commit 的代码链接，不要只给可能变化的主分支链接。
5. 上传匹配的 `MP1_checkpoints.zip`，确保评审可直接下载。它包含最终模型以及用于资源对照的基线 checkpoint。
6. 重新解压代码和 checkpoint 到同一目录后，按 `REPRODUCE.md` 运行 CPU FP32 完整测试。无需重新训练。
7. 在课程网站填写本人的学号、完整测试 BPB、固定版本代码链接和 checkpoint 链接。生成 GitHub issue 后，还需在 GitHub 确认创建。
8. 本地 GUIDE 要求 9 月 29 日前先报分，9 月 30 日（UTC+8）前最终提交代码、模型和不超过 10 页的报告；如有更新，以教师最新通知为准。建议 9 月 28 日前完成首次提交。
9. 若 Moodle 后续要求单独提交报告，再按教师通知提交该 PDF。
